## Another Quick Switcher

### 说明

Another Quick Switcher 是 Obsidian 自带快速切换功能的增强版，主要用于快速查找并打开笔记、标题、标签和最近使用的文件。

### 常用用法

#### 搜索并打开笔记

1. 打开 Another Quick Switcher 搜索窗口。
    
2. 输入文件名或关键词。
    
3. 使用方向键或鼠标选择结果。
    
4. 按回车或单击结果打开笔记。
    

不需要输入完整文件名，输入部分关键词通常也可以找到。

#### 搜索笔记中的标题

使用插件提供的标题搜索功能，可以直接搜索整个仓库中的标题。

例如输入：

```text
文件权限
```

可以直接找到包含“文件权限”标题的位置，而不需要先打开对应笔记。

#### 查看最近使用的笔记

插件可以根据最近打开时间排列笔记，适合快速回到刚才编辑或查看的内容。

#### 使用搜索历史

再次打开搜索窗口时，可以查看之前搜索过的内容，方便重复查找同一个笔记或标题。

#### 设置快捷键

进入：

```text
设置
→ 快捷键
→ 搜索 Another Quick Switcher
```

设置为了Ctrl+O；在搜索框里可以按”Ctrl+，“在背后查看打开的文件

### 适用场景

- 笔记数量较多时快速找文件；
    
- 不知道笔记保存在哪个文件夹时；
    
- 直接跳转到某篇笔记中的指定标题；
    
- 快速打开最近编辑过的笔记。

## Better Export PDF

### 说明

Better Export PDF 用于将 Obsidian 笔记导出为 PDF，并提供比原生导出更完整的排版和导出设置。

### 常用用法

#### 导出当前笔记

1. 打开需要导出的笔记。
    
2. 点击笔记页面右上角的更多选项按钮。
    
3. 查找 Better Export PDF 的导出选项。
    
4. 进入导出预览页面。
    
5. 检查排版后选择保存位置。
    

如果右上角菜单中没有显示导出选项，可以从插件命令中打开导出功能。

#### 从文件列表导出

在左侧文件列表中右键单击 Markdown 笔记，查看是否有 Better Export PDF 的导出选项。

部分导出方式也支持选择多个文件后统一导出。

#### 调整导出设置

进入：

```text
设置
→ Better Export PDF
```

可以设置：

- 页面大小；
    
- 页面方向；
    
- 页边距；
    
- 页码；
    
- 页眉和页脚；
    
- PDF 书签；
    
- 是否显示文件名；
    
- 标题和正文样式。
    

#### 导出前检查

导出前建议检查：

- 图片是否完整显示；
    
- 表格是否超出页面；
    
- 代码块是否被截断；
    
- 标题层级是否正确；
    
- 是否需要页码；
    
- 是否需要生成 PDF 目录或书签。
    

### 适用场景

- 导出课程笔记；
    
- 制作复习资料；
    
- 保存实验报告；
    
- 打印学习文档；
    
- 将多篇笔记整理为一份 PDF。

## Excalidraw

### 说明

Excalidraw 可以在 Obsidian 中创建手绘风格的流程图、结构图、思维导图和知识关系图。

绘图文件会保存在当前 Obsidian 仓库中，可以像普通笔记一样管理。

### 适用场景

- 绘制 Linux 系统结构；
    
- 整理程序执行流程；
    
- 绘制驱动框架；
    
- 制作知识关系图；
    
- 绘制硬件连接图；
    
- 制作思维导图。

## File Explorer Note Count

### 说明

File Explorer Note Count 会在左侧文件列表的文件夹名称后显示文件数量。

插件启用后会自动工作，不需要每次手动运行。

### 常用用法

#### 查看文件数量

启用后，左侧文件夹会显示类似：

```text
Linux（12）
STM32（8）
课程笔记（20）
```

括号中的数字表示文件夹内包含的文件数量。

#### 查看子文件夹总数

根据插件设置，显示的数字可以只统计当前文件夹，也可以包含所有子文件夹中的文件。

#### 修改统计方式

进入：

```text
设置
→ File Explorer Note Count
```

可以调整：

- 是否统计子文件夹；
    
- 是否显示文件夹总数；
    
- 文件夹展开时是否继续显示数量；
    
- 数字的显示样式。
    

### 适用场景

- 查看不同分类中的笔记数量；
    
- 判断某个学习目录的内容规模；
    
- 检查文件夹中是否已经包含笔记；
    
- 管理笔记较多的仓库。

## Hover Editor

### 说明

Hover Editor 可以把 Obsidian 的链接预览窗口变成可编辑的小窗口。

使用它时，不需要离开当前笔记，就可以查看或修改另一篇笔记。

### 常用用法

#### 打开悬浮编辑窗口

在笔记中找到内部链接，例如：

```markdown
[[Linux命令]]
```

按住 `Ctrl`，然后把鼠标移动到链接上。

出现悬浮窗口后，可以直接查看目标笔记。

#### 转为普通标签页

需要长期查看某篇笔记时，可以通过悬浮窗口菜单将它打开为普通标签页。

#### 检查页面预览

如果鼠标悬停没有反应，应检查：

```text
设置
→ 核心插件
→ 页面预览
```

确保“页面预览”已经开启。

#### 修改插件设置

进入：

```text
设置
→ Hover Editor
```

可以调整悬浮窗口的行为、大小和打开方式。

### 适用场景

- 写笔记时参考另一篇笔记；
    
- 同时查看概念说明和实际示例；
    
- 不离开当前页面就补充被链接笔记；
    
- 对照多篇学习资料；
    
- 临时打开相关笔记。

## Quiet Outline

### 说明

Quiet Outline 是一个增强版大纲面板，可以替代 Obsidian 自带的大纲。

它会读取当前笔记中的标题，并按照标题层级生成目录。

### 常用用法

#### 打开 Quiet Outline 面板

可以通过以下方式打开：

- 点击 Quiet Outline 提供的侧边栏图标；
    
- 使用打开 Quiet Outline 面板的命令。
    

打开后，可以把面板拖动到左侧或右侧边栏。

#### 替代原生大纲

Quiet Outline 和 Obsidian 自带大纲是两个不同的面板。

使用 Quiet Outline 后，可以关闭原生大纲，只保留新的大纲面板。

#### 保存展开状态

如果插件版本提供状态保存选项，可以在设置中开启，使每篇笔记尽量保留各自的展开和折叠状态。

### 适用场景

- 阅读标题较多的长篇笔记；
    
- 快速跳转到某个章节；
    
- 折叠暂时不需要查看的目录；
    
- 按每篇笔记管理目录状态；
    
- 替代 Obsidian 原生大纲。
