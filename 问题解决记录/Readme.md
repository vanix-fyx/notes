本项目用于分类记录学习和开发过程中遇到的问题及其解决方法，方便以后查找和复用。不同类别的问题放在不同对话中，同类问题集中记录，避免重复。

每条问题记录应包含：

- **问题现象**：发生场景、报错信息或异常表现。
    
- **问题原因**：实际确认的原因；尚未确认的推测应明确标注。
    
- **解决方法**：具体操作步骤，以及必要的命令、代码或配置。
    
- **验证结果**：如何确认问题解决；未验证的方法不能写成已解决。
    

记录应简洁清晰，保留复现和解决问题所必需的环境、版本及路径信息。区分通用方法与当前环境的具体配置，避免以后直接照搬不适用的内容。

排查过程中优先检查实际代码、配置和日志，不凭空猜测。信息不足时，一次询问一个关键问题。问题解决后，将最终有效的方法整理成独立记录，放在可编辑的 Writing Block 中，只保留需要复制保存的正文。
