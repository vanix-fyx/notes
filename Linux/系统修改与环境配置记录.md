## 一、i.MX6ULL 开发板

### 1. `/root/.adbshrc`

#### 用途

该文件会在通过：

```sh
adb shell
```

进入开发板时自动执行。

`/etc/init.d/S99adbd` 中存在：

```sh
export ENV=/root/.adbshrc
```

因此 `adb shell` 会加载 `/root/.adbshrc`。

---

#### 1.1 修改 ADB Shell 终端行列数

当前配置：

```sh
stty rows 35 cols 51 2>/dev/null
```

作用：

```text
rows 35    设置终端为 35 行
cols 51    设置终端为 51 列
```

查看当前终端尺寸：

```sh
stty size
```

正常应显示：

```text
35 51
```

该设置主要用于适配当前使用的终端窗口大小。

---

#### 1.2 自定义 ADB Shell 命令提示符

当前 `/root/.adbshrc` 中设置了：

```sh
export PS1='\[\033[1;32m\][\u@\h\[\033[0m\]:\[\033[1;34m\]\w\[\033[1;32m\]]\[\033[0m\]\n\[\033[1;33m\]\$\[\033[0m\] '
```

作用是将提示符显示为两行，例如：

```text
[root@100ask:/FYX/hardware/07_input/02_tslib]
#
```

并带有颜色显示。

不要随意执行会重新修改 `PS1` 的配置，否则可能改变该显示格式。

---

#### 1.3 ADB Shell 自动配置 tslib 环境变量

为了让每次执行：

```sh
adb shell
```

后都能直接使用 tslib，已经将以下环境变量加入 `/root/.adbshrc`：

```sh
# tslib environment
export TSLIB_CONFFILE=/etc/ts.conf
export TSLIB_PLUGINDIR=/usr/lib/ts
export TSLIB_TSDEVICE=/dev/input/event1
export TSLIB_CALIBFILE=/etc/pointercal
```

各变量作用：

|环境变量|当前值|作用|
|---|---|---|
|`TSLIB_CONFFILE`|`/etc/ts.conf`|指定 tslib 配置文件|
|`TSLIB_PLUGINDIR`|`/usr/lib/ts`|指定 tslib 插件目录|
|`TSLIB_TSDEVICE`|`/dev/input/event1`|指定触摸屏输入设备|
|`TSLIB_CALIBFILE`|`/etc/pointercal`|指定触摸屏校准文件|

检查：

```sh
env | grep TSLIB
```

这些变量最初如果没有设置，会导致程序调用：

```c
ts_setup(NULL, 0);
```

时报错，例如：

```text
Couldn't open tslib config file : No such file or directory
ts_config: No such file or directory
ts_setup err
```

设置后，自己编写的 tslib 程序以及 `ts_print` 等工具可以正常找到配置文件和插件。

### 2. tslib 相关系统文件

#### 2.1 `/etc/ts.conf`

当前 tslib 配置文件位置：

```text
/etc/ts.conf
```

已确认文件实际存在。

当前有效配置包括：

```text
module_raw input
module pthres pmin=1
module dejitter delta=100
module linear
```

该文件决定 tslib 加载哪些触摸数据处理模块。

---

#### 2.2 `/usr/lib/ts/`

当前 tslib 插件实际安装目录：

```text
/usr/lib/ts
```

已经确认其中存在：

```text
/usr/lib/ts/input.so
```

因此必须让：

```sh
TSLIB_PLUGINDIR=/usr/lib/ts
```

否则会出现：

```text
Couldn't load module input
No raw modules loaded.
```

---

#### 2.3 `/etc/pointercal`

tslib 使用的触摸屏校准文件路径：

```text
/etc/pointercal
```

对应环境变量：

```sh
export TSLIB_CALIBFILE=/etc/pointercal
```

### 3. LVGL 图形界面运行状态控制

开发板当前开机运行的图形界面程序是：

```text
/usr/share/lvgl/lvgl_100ask_demo
```

由以下 SysV init 启动脚本管理：

```text
/etc/init.d/S05lvgl
```

> **该脚本本身没有修改，只是在实验时调用它控制程序运行状态。**

运行 tslib 图形测试前，为避免 LVGL 与 `ts_test_mt` 同时占用 framebuffer 和触摸屏，需要执行：

```sh
/etc/init.d/S05lvgl stop
```

测试：

```sh
ts_test_mt
```

测试结束后恢复 LVGL：

```sh
/etc/init.d/S05lvgl start
```

视频中使用的：

```sh
systemctl stop myir
```

不适用于当前开发板系统。

当前开发板 PID 1 为：

```text
init
```

系统没有：

```text
systemctl
```

因此主要使用 `/etc/init.d/` 下的启动脚本管理服务。


```text
libtool 行为差异
```

因此以后遇到类似情况时，应首先考虑：

```text
课程原始 Ubuntu 环境
        ≠
当前升级后的 Ubuntu 20.04.6 环境
```
